# ADR 0001: 로컬 서버 세션 기반 직원 인증

- 상태: 채택
- 날짜: 2026-11-12
- 범위: FastAPI 직원 인증 및 RBAC

## 배경

이 프로젝트는 개인 학습·포트폴리오 용도의 로컬 시스템이다. 학생 로그인은 범위가 아니며
ADMIN, TEACHER, ASSISTANT만 인증한다. 유료 인증 SaaS와 클라우드 리소스를 사용할 수 없고,
브라우저에 장기 자격 증명을 노출하지 않아야 한다.

## 결정

- PostgreSQL에 불투명 세션의 SHA-256 digest만 저장한다.
- 브라우저에는 `HttpOnly`, `SameSite=Lax` 세션 쿠키를 저장한다. HTTPS 환경에서는
  `Secure`를 강제하며 로컬 HTTP 개발에서만 명시적으로 해제한다.
- 상태 변경 요청은 별도 CSRF cookie와 `X-CSRF-Token`을 함께 검증한다.
- 비밀번호는 Argon2id로 해시하고 평문, 세션 원문, CSRF 원문은 DB와 로그에 남기지 않는다.
- 서버가 DB의 role과 담당 반 배정을 매 요청마다 판정한다. 클라이언트 role header는
  권한 근거로 사용하지 않는다.

## 결과와 제한

외부 인증 비용과 토큰 폐기 복잡도 없이 로그아웃·계정 비활성화를 즉시 반영한다. 현재 로그인
rate limiter는 단일 프로세스 메모리 방식이므로 로컬 단일 인스턴스에 적합하다. 다중 프로세스나
외부 공개 환경으로 확장할 때는 PostgreSQL 기반 제한 또는 무료 자체 호스팅 저장소를 별도
설계해야 한다. 이 결정은 외부 공개 배포를 승인하지 않는다.

## 롤백

애플리케이션을 이전 버전으로 내리고, 필요하면 사전 `pg_dump`로 복원한다. Alembic downgrade는
인증 테이블을 삭제하므로 데이터 보존 검토 없이 실행하지 않는다.
