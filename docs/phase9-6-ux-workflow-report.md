### Phase 3 — 엑셀 업로드(`UploadTab`)
- 1단계는 미리보기 후 한 줄 요약(파일·크기·수업일 + "파일·수업일 바꾸기")으로 접힘

## 6. 남은 제한·위험
- **브라우저 미검증**: 하단 고정 저장 바(sticky)는 상위 요소의 overflow 설정에 따라 동작이 달라질 수 있음, 1366/1440/1920 폭에서 표 줄바꿈·가로 스크롤, 모달·키보드 탐색은 실제 화면에서 확인 필요(9.5 수동 체크리스트와 함께 권장)
- 업로드 결과 분류는 서버 문구 1개(`notifications/service.py:342`)에 의존 — 문구가 바뀌면 기존 초안 학생이 다시 "실패"로 보임(안전한 쪽으로 실패). 생성 불가 사유 바로가기도 `engine.py` 문구에 의존, 일치하지 않으면 바로가기만 사라지고 사유는 그대로 표시
- 작업 반 기억은 브라우저 탭 단위(sessionStorage). 같은 탭에서 다른 계정으로 로그인해도 서버가 준 반 목록 밖의 반은 고르지 않음
- 메시지 처리 현황 화면은 여전히 `?status`를 열 때 한 번 읽음(기존 동작)
