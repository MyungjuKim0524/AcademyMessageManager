# Phase 10 — 수동 테스트 체크리스트 (브라우저)

실행: `scripts/start-fastapi.ps1`, `scripts/start-frontend.ps1` → http://127.0.0.1:5173 → 사이드바 **학사 운영 › 출결·성적 분석**.
관리자 비밀번호는 직접 입력하세요. 결과 칸은 실행 전 상태 **NOT RUN**(이 환경에는 브라우저 자동화 도구가 없음).

| 3 | 진행 기록 없는 수업 | 지난 '예정' 수업이 있으면 노란 안내 + "수업 목록 확인" 이동 (개발 DB에 3건 존재) | NOT RUN |

| 14 | 배정 해제·비활성 | 관리자가 배정 해제 → 해당 반 조회 403, 비활성화 → 다시 로그인 요구 | NOT RUN |
