# Phase 8.1 — 엑셀 업로드 기반 학부모 안내 보고서

작성일: 2026-11-19 · 선행: `docs/archive/phases/phase8-parent-notification-workflow.md` · 진행: `docs/archive/phases/phase8-progress.md`

## 1. 목표

조교가 학원 주간 엑셀(시트 = 시간대, 반 블록 반복)을 올리면 반별 출결·과제 등급·시험 점수가 저장되고,
수업 유형별 **기본 템플릿**으로 학부모 안내 초안이 자동 생성된다. 메시지 생성 경로는 "엑셀 업로드 → 검토·발송"으로
통일하고, 기존 수동 생성은 '누락·예외 생성' 탭으로 축소했다. 실제 발송·외부 API는 여전히 없음(모의 발송만).

## 2. 업무 규칙 (2026-11-19 사용자 결정)

엑셀 형식 — 반 블록 머리글(2번째 칸이 "출결") 아래에 학생 행:

```
중3 토10 | 출결 | 예습 과제 | 주간 과제 | 문법, 문학, 독서 (15) | 어휘 (10)
(학생)   | 출석 | A        | A        | 15                     | 10
```

| 항목 | 규칙 |
|---|---|
| 반 유형 | "중3 토10", "고1 토10A" = 정규(REGULAR) · "00고2 토10", "**고2 토6" = 내신 대비(EXAM_PREP) · 그 외(예: "002 토2") = 오류 |
| 프로그램에 없는 반 | 오류 — 관리자가 먼저 반 등록 |
| 시험 칸 | 맞은 개수(또는 "12/15"), 전체 문항 수 = 머리글 괄호. 분야 이름의 쉼표 뒤 공백 통일 |
| 과제 등급 | A/B/C만 허용(D 등은 오류), 빈 칸 = 미입력 |
| 이름만 있는 행 | 메모로 보고 건너뜀(SKIPPED) |
| 수업 | 수업일은 화면에서 지정(파일 1개 = 하루). (반, 날짜, 1교시)로 찾고 없으면 COMPLETED로 생성. 미래 날짜 거부, 취소된 수업이면 오류 |
| 출결 | 앱 기록 없음 → 엑셀 값 저장 / 같음 → 통과 / **다름 → 앱 값 유지 + "출결 불일치"(노랑) + 그 학생 초안 미생성** |
| 과제·점수 | 반·학생별 저장·갱신. 분야 = 수업에 연결된 평가(assessment, 수업당 제목 UNIQUE → 재업로드 시 갱신). 결석·인정결석 학생의 빈 점수 = NOT_TAKEN(미응시), 출석 학생의 빈 점수 = 저장 안 함 |
| 학생 매칭 | 반 안에서 이름 정확히 일치. 엑셀 안 동명 중복·반 안 동명이인 = 오류 |
| 미등록 학생(빨강) | "신규 수강생인가요?" 예 → 그 반 등록(NEW) / 아니요 → "복귀 학생인가요?"(휴원 중일 때만) 예 → 휴원→재원, 복귀일 = 수업일(RETURNING) / 아니요 → "오류로 간주해 해당 행은 성적 안내 메시지를 생성하지 않겠습니다." 후 제외(EXCLUDE). 퇴원 학생은 신규·복귀 불가 |
| 확정 권한 | 파일의 모든 반이 본인 담당일 때만(관리자는 전체). 조교·선생님도 신규 등록·복귀 처리 가능, 이력 기록 |
| 초안 | 확정 후 수업 유형별 기본 템플릿으로 자동 생성. 보호자 이메일 없는 학생은 건너뜀 사유 표시 |

## 3. 정책·화면 용어 변경과 근거

| 변경 | 근거 |
|---|---|
| 메뉴 첫 화면 `/notifications`, 탭: **엑셀 업로드(기본)**·검토·발송·누락·예외 생성·템플릿 | 실제 업무가 "엑셀 작성 → 안내"이므로 생성 경로를 하나로 통일(사용자 요구) |
| 메뉴에서 "메시지 미리보기", "CSV/XLSX 미리보기" 숨김 | 업로드로 대체. 라우트·API(`/api/messages/preview`, `/api/imports/*`)는 Java 호환을 위해 유지 |
| 템플릿 탭 "엑셀 업로드 기본" 지정(정규/내신 대비/없음) | 업로드 초안이 쓸 템플릿을 관리자가 고르도록 |
| `{성적요약}` "어휘 8/10점" → **"어휘 8/10"** | 점수가 맞은 개수이므로 "점"은 오해 소지(사용자 결정) |
| 출결 탭: 미입력 학생을 **화면에서만** "출석"으로 미리 선택 + "저장 안 됨" 표시, "미입력 학생 모두 출석" 버튼 제거 | 입력 수고를 줄이되, 저장 전에는 DB를 바꾸지 않아 "미입력 ≠ 출석" 원칙 유지 |
| 화면 용어 "승인" → "내용 확정"(Phase 8에서 결정, 유지) | 조교가 직접 확정·모의 발송 |

## 4. API

| 메서드 | 경로 | 내용 |
|---|---|---|
| POST | `/api/lesson-uploads/preview` | multipart `file`, `lesson_date`. **쓰기 없음.** 반 블록·행 상태(MATCHED/UNREGISTERED/INVALID/SKIPPED)·문제·경고·`can_confirm`·`blocking` 반환 |
| POST | `/api/lesson-uploads/confirm` | CSRF 필요. `file`, `lesson_date`, `decisions`(JSON `{행키: NEW\|RETURNING\|EXCLUDE}`). 한 트랜잭션으로 저장 후 초안 생성. 결과: 저장 행 수·신규·복귀·제외·출결 불일치·반별 초안 수/건너뜀 |
| PATCH | `/api/notification-templates/{id}` | `default_for_class_type`: `REGULAR`/`EXAM_PREP`/`"NONE"`. 지정 시 이전 기본 자동 해제, 비활성 템플릿은 기본 불가(비활성화하면 기본 해제) |

주요 오류 코드: `FILE_TOO_LARGE`(413), `FILE_REQUIRED`, `LESSON_IN_FUTURE`, `UPLOAD_HAS_ERRORS`, `DECISION_REQUIRED`,
`INVALID_DECISIONS`, `NOT_A_NEW_STUDENT`, `NOT_A_RETURNING_STUDENT`, `INVALID_PAUSE_DATES`(400), `UPLOAD_CONFLICT`(409).

### 7.2 업로드 결과 — 초안 미생성 빨간 팝업 (2026-11-19, 사용자 요청)

브라우저 확인에서 신규 학생(보호자 이메일 없음)의 초안이 건너뛰어졌는데, 결과 카드에 회색 글씨로만 표시되고 상단 알림은 초록색 "초안 N건을 만들었습니다"라서 알아채기 어려웠다.
→ 확정 후 건너뜀·출결 불일치가 1건이라도 있으면 **빨간 팝업**("메시지 초안을 만들지 못한 학생이 있습니다")에 반별 사유 목록과 조치 방법을 표시하고,
상단 알림도 빨간색으로 "초안을 만들지 못한 항목 N건"을 알린다. 결과 카드의 사유도 빨간 글씨("초안 미생성 — …").
테스트: notifications 6 PASS(신규 1, 기존 업로드 테스트에 팝업 확인 추가), tsc·oxlint·build PASS.

### 7.3 학습 현황 탭 — 조회·수정 한 곳으로 (2026-11-19, 사용자 결정)

배경: 회차별·반별 출결·과제 등급·점수를 한눈에 볼 화면이 없었고, **과제 등급은 화면에서 볼 수도 고칠 수도 없었다**(엑셀 재업로드뿐).
사용자 업무 흐름: 수업 시작 시 **출결을 먼저 앱에 기록**(지각·결석은 카운터에서 학부모 전화) → 과제·점수는 수업 중 시간 차를 두고 기록.
모든 데이터는 잘못 입력될 수 있으므로 수정은 한 곳(학습 현황)에서 한다.

| 영역 | 내용 |
|---|---|
| 탭 구성 | 수업·출결·성적: **출결(기본)** · **학습 현황** · 수업 · **평가 관리**(구 '성적') |
| 학습 현황 | (※ 2026-11-20 일 단위 표로 변경 — 7.6 참고) 반·기간(기본 최근 4주, 최대 3개월) 표 — 행=학생, 열=수업 회차(날짜·교시·주제)와 수업에 연결되지 않은 평가. 칸: 출결 태그, "예습 A · 주간 B", "어휘 8/10"/"미응시"/"-"(미입력≠0점). 회색=휴원·수강 기간 밖("대상 아님"). 탭을 열 때마다 새로 조회 |
| 칸 수정 | 칸 클릭 → 출결·예습/주간 등급(A/B/C/미입력)·연결 평가 점수(미응시 포함)를 **한 트랜잭션**으로 저장. 버전 검사(동시 수정 409), 이력(`ATTENDANCE_*`, `ASSIGNMENT_GRADES_UPDATED`(신규), `GRADE_*`). 연결 안 된 평가 칸은 기존 점수 API로 저장(메모 보존) |

### 7.4 출결 탭 "오늘 수업 시작" (2026-11-19, 사용자 결정)

문제: 수업 시작 때 조교가 출결을 먼저 기록하는데, 수업 등록은 선생님·관리자만 가능해 그날 수업이 미리 없으면 조교가 출결을 입력할 수 없었다.
결정: 조교에게 수업 등록·수정·취소 전체를 여는 대신, 출결 탭에 **"오늘 수업 시작"** 버튼을 둔다(수업 주제·날짜 수정·취소는 선생님·관리자 유지).

| 영역 | 내용 |
|---|---|
| API | `POST /api/classrooms/{id}/lessons/today` (CSRF, 출결 기록 권한 = 관리자·선생님·조교, 담당 반만). 오늘·1교시 수업을 찾고 없으면 생성(상태 '완료', 엑셀 업로드가 만드는 수업과 동일). **멱등**: 이미 있으면 그대로 반환(`created: false`), 동시에 두 명이 눌러도 1개만 생성. 오늘 1교시 수업이 취소 상태면 409 `LESSON_CANCELLED`. 이력 `LESSON_CREATED`(`source: ATTENDANCE_START`) |
| 화면 | 출결 탭: 오늘 날짜 수업이 없을 때만 "오늘 수업 시작" 버튼(카드 상단, 수업이 하나도 없을 때는 빈 화면 안). 누르면 수업이 만들어지고 바로 그 수업의 출결 입력 화면이 열림 |
| 테스트 | pytest **102 PASS / 0 skip**(신규 2: 조교 시작·멱등·이력·출결 기록·수업 수정 403·다른 반 403·CSRF / 취소된 오늘 수업 409), Vitest classwork 11 PASS(신규 1: 조교 버튼 → 생성 → 출결 화면 → 버튼 사라짐), 전체 Vitest **46 PASS**(11 files), tsc·oxlint·build PASS |

### 7.6 사용자 브라우저 확인 후 개선 (2026-11-20)

사용자가 브라우저에서 1~8 항목(전체 학생·수강 등록, 반 배정, 오늘 수업 시작, 학습 현황 수정·확인 팝업, 평가 관리, 업로드 빨간 팝업, 검토·모의 발송)을 직접 확인한 뒤 요청한 3건.

| # | 요청 | 구현 |
|---|---|---|
| 1 | 엑셀로 생성된 신규 학생의 학교를 수강 반에 맞춰 자동 배정 | 업로드에서 "신규 수강생 → 예"로 학생을 만들 때 **내신 대비 반 이름에서 학교명 추출**("00고2 토10" → "00고", "검증고2 내신" → "검증고")해 `student.school_name`에 저장. 같은 (이름, 학교) 학생이 있으면 재사용(학생 고유키 = 이름+학교). **정규반**("중3 토10", "고1 토10A")은 반 이름에 학교 정보가 없어 학교를 비워 둠 → 필요하면 관리자가 학생 정보에서 입력. 이력 `ENROLLMENT_CREATED_FROM_UPLOAD`에 `school_assigned` 추가. 코드: `lesson_upload/workbook.py:school_of`, `lesson_upload/service.py` |
| 2 | 학습 현황을 일 단위로, 열은 학생·과제명·시험 종목명 | 하루를 골라(◀ 전날 / 날짜 / 다음날 ▶ / 오늘) 표 표시: **학생 \| 예습 과제 \| 주간 과제 \| 시험 종목별 열("어휘 (10)" …)**. 값: 등급 A/B/C, 점수(맞은 개수)·"미응시"·"-"(미입력). 같은 날 2교시 이상이면 "교시 선택". 그날의 수업 미연결 평가도 시험 열로 표시. 출결 열은 표에서 빠짐('출결' 탭에서 확인) — 칸 수정 창에서는 출결도 계속 고칠 수 있음. 칸 클릭 → 기존 수정 창·변경 확인 팝업 그대로. API는 기존 `GET /progress`를 `date_from = date_to = 그날`로 사용(백엔드 변경 없음) |
| 3 | '학부모 안내' → '성적 안내' (이름만) | 메뉴, 페이지 제목, 404 화면 버튼, 학생 화면의 보호자 이메일 안내 문구("성적 안내 수신", "성적 안내 메시지는 이 이메일로…"). 경로(`/notifications`)·API·DB 이름은 그대로 |

## 8. 남은 제약

- 학생 매칭은 반 안에서 이름 정확히 일치만. 같은 반 동명이인은 오류로 막음.
- 신규 등록 학생은 보호자 이메일이 없어 초안이 건너뛰어짐 → 관리자가 "연락처 수정" 후 '누락·예외 생성'으로 생성.
- 출결 불일치 학생도 출결 확인 후 '누락·예외 생성'으로 수동 생성.
- 업로드 이력 전용 화면 없음(`audit_log`만).
- 파일 1개 = 수업일 하루, 1교시 수업만 대상.
