# Phase 9.5 수동 UI 체크리스트

준비: Docker Desktop 실행 → `docker start academy-learningops-postgres-dev` → 터미널 ① `.\scripts\start-fastapi.ps1` → 터미널 ② `.\scripts\start-frontend.ps1` → http://localhost:5173 (Ctrl+F5).
비밀번호는 직접 입력하세요(문서·로그에 남기지 않음). 실제 문자·이메일은 발송되지 않습니다(모의 발송).
가상 학생만 사용하세요. 실패 시연용 보호자 이메일: `가상@mock-retry.invalid`(첫 발송만 실패), `가상@mock-fail.invalid`(항상 실패).
